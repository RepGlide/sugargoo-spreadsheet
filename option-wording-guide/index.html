Option Wording Guide

Read color, size, version, quantity, and set wording against the current page and selection.

Option words are not portable

A color, size, version, quantity, or set name only means something beside the page it came from and the option you actually selected. Read in isolation, an option word looks like a fact; read in context, it is a pointer back to a specific selection.

Color — a name, not a shade

Two listings can share a color name and show different shades. Keep the name and re-check it against the selected option on the current page instead of trusting the word alone.

Size — a label, not a measurement

The same size label can mean different measurements across products and brands. Re-check the actual dimensions or fit rather than treating the name as an absolute value.

Version — a name, not a specification

A version label depends on the generation, material, or spec it refers to. Mark it open until the page ties the name to the selection you made.

Quantity — a name, not a count

Single, set, and multi-piece are distinct options that can share a loose label. Re-check what the selected quantity actually includes.

Set — a name, not its contents

A set label only means something beside its listed contents. Re-check what is explicitly included before relying on the name.

Ticket ruleThe option name and the selected option are two lines that must be read together. Never carry a name away from the selection that gives it meaning.

A worked reading

  1. Option name: kept exactly as it appears in the selector.
  2. Current page: the page you actually opened, noted.
  3. Actual selection: the option you chose, recorded.
  4. Re-check: the name and selection read together before any judgment.
